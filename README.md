## Featured Projects

### [Krynix](https://krynix.io/)
Agent behavioural trust verification toolkit. Traces agent action sequences, detects anomalies in 
decision trajectories, and acts as a CI gate to block deployment of agents exhibiting unexpected 
behaviour. Framework-agnostic, local-first, zero data exfiltration.

**Python · TypeScript · CLI · CI/CD integration**

---

### [RefineX](https://github.com/artificialvirus/RefineX)
Verification-guided LLM reasoning system. Couples a generator with typed verifiers — arithmetic, 
symbolic algebra via SymPy, formal logic — and an iterative controller that runs detect → verify 
→ revise loops. Supports OpenAI, Anthropic, and local inference via Ollama.

Related to MSc dissertation research in agentic self-correction.

**Python · FastAPI · Docker · Kubernetes**

---

### [mlops_observe](https://github.com/artificialvirus/mlops_observe)
MLOps observability platform for ML event ingestion, drift and fairness monitoring, and alerting. 
ClickHouse-backed with Python and Node SDKs, CLI tooling, RBAC, and SSO via OIDC.

**Python · FastAPI · ClickHouse · Prometheus · Docker**
